# Ming Zhang Homepage

This repository contains the source for Ming Zhang's personal academic homepage, deployed with GitHub Pages at [konglonggefdu.github.io](https://konglonggefdu.github.io/).

The site is intentionally lightweight:

- `index.html` contains the profile, news, selected works, and publication entries.
- `style.css` controls the page layout and visual style.
- `pic/` stores publication and project images used by the page.

To update the homepage, edit the relevant HTML/CSS files and push to `main`. GitHub Pages will publish the new version automatically.
